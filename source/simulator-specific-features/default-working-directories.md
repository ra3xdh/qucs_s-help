# Default Working Directories

Qucs-S uses one shared working directory for the external SPICE-family simulators: ngspice, SpiceOpus, and Xyce. Simulation working files are placed there as required by the backend.

For ngspice and SpiceOpus, the local `.spiceinit` file generated by Qucs-S (see [Using .spiceinit Files](/simulator-specific-features/classic-spice-engines/using-spiceinit)) is also placed there.

## Default Location

By default, this working directory is a `qucs-s` folder created inside the current user's standard operating-system cache location.

### Linux

```text
$HOME/.cache/qucs-s
```

### macOS

The Qucs-S folder within the user's standard macOS cache location (the parent location is `~/Library/Caches`).

### Windows

The Qucs-S folder within the user's local application cache/data location (the parent location is `%LOCALAPPDATA%`).

```{note}
The exact resolved path may vary with the Qt version Qucs-S was built against, OS configuration, packaging, or an existing value already persisted in the Qucs-S configuration.
```
